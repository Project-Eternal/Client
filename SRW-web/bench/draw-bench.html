WebGL vs WebGPU draw benchmark

A scene shaped like a World of Warcraft 3.3.5a frame (about 450 draws, 100k triangles, alpha blending, per-draw matrices and textures), drawn through WebGL 2 with the call pattern of the Direct3D 9 layer and through WebGPU. It measures how long a frame takes to finish on the GPU, without waiting for the display, and how long the CPU spends issuing it.

  • Keep this tab in front and the window focused while it runs. Close other graphics-heavy apps.
  • WebGPU has only 1x and 4x multisampling; WebGL can do 2x as the game does.
  • The rows with uploads repeat the game's habit of updating its dynamic buffers about 300 times per frame between draws that read them; inline is the game's order, upfront does all updates before the first draw, other updates a buffer no draw reads.
  • Press Run suite (about a minute), then Copy results and paste them back.
